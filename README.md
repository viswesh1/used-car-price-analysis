# Used Car Price Analysis

## Project Overview
This project performs end-to-end analysis of used car data by collecting data through web scraping using Python and analyzing it in Power BI to identify pricing trends and best value vehicles.

## Tools Used
- Python (Selenium, BeautifulSoup) — Web Scraping
- Power BI (Power Query, DAX, Visualization) — Cleaning, EDA, Dashboard

## Workflow
1. Scraped used car data from website using Python
2. Imported data into Power BI
3. Cleaned and transformed data using Power Query
4. Performed exploratory data analysis
5. Built interactive dashboards to visualize insights

## Key Insights
- Price trends vary with car age and fuel type
- Identified best value cars in certain price ranges
- Observed patterns in mileage and transmission
